# Icon attribution

Technology brand marks in this folder are the real, full-color logos:

- 18 marks from [Simple Icons](https://simpleicons.org/) (CC0 1.0 Universal),
  fetched brand-colored via `cdn.simpleicons.org`: github, git, docker,
  kubernetes, redis, postgresql, mongodb, apachekafka, terraform, prometheus,
  grafana, linux, python, nodedotjs, react, nginx, npm, postman.
- AWS and VS Code are absent from Simple Icons (trademark removals), so those
  two come from [Devicons](https://devicons.github.io/) (MIT): AWS wordmark,
  VS Code original.

Rendered in true brand colors on light specimen tiles — do not recolor.
Brand guidelines of the respective owners still apply — used here for
identification in a quiz.
