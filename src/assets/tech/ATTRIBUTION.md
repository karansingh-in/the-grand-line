# Icon attribution

Technology brand marks in this folder are the real, full-color logos:

- 17 marks from [Simple Icons](https://simpleicons.org/) (CC0 1.0 Universal),
  fetched brand-colored via `cdn.simpleicons.org`: github, git, docker,
  kubernetes, postgresql, mongodb, apachekafka, linux, python,
  nodedotjs, react, npm, claude, perplexity, gemini, antigravity,
  spacex (redis, postman, nginx and kafka retired).
- openai and adobe come from the pinned Simple Icons v13 set with official
  brand fills applied (#000000, Adobe #FA0F00) — absent from the live
  color endpoint.
- Google Antigravity is absent from Simple Icons, so its mark is the
  official logo cropped from Wikimedia Commons (File:Google Antigravity
  Logo.svg); Gemini (googlegemini) comes from Simple Icons.
- AWS and VS Code are absent from Simple Icons (trademark removals), so those
  two come from [Devicons](https://devicons.github.io/) (MIT): AWS wordmark,
  VS Code original.

Rendered in true brand colors on light specimen tiles — do not recolor.
Brand guidelines of the respective owners still apply — used here for
identification in a quiz.
