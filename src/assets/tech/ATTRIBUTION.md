# Icon attribution

Everyday-app brand marks in this folder are the real, full-color logos,
picked so non-technical players recognize them instantly:

- 16 marks from [Simple Icons](https://simpleicons.org/) (CC0 1.0 Universal),
  fetched brand-colored via `cdn.simpleicons.org`: instagram, whatsapp,
  youtube, googlechrome, gmail, google, netflix, spotify, facebook,
  googlemaps, snapchat, telegram, android, apple, googlepay, x.
- amazon, linkedin, openai come from the pinned Simple Icons v13 set with
  official brand fills applied (Amazon #FF9900, LinkedIn #0A66C2,
  OpenAI #000000) — both were removed from later releases.
- samsung comes from [Devicons](https://devicons.github.io/) (MIT).

Rendered in true brand colors on light specimen tiles — do not recolor.
Brand guidelines of the respective owners still apply — used here for
identification in a quiz.
